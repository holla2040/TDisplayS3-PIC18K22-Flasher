# TDisplayS3-PIC18K22-Flasher Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A T-Display S3 jig that programs PIC18(L)F2x/4xK22 over HV ICSP, driven by a text script on FFat, keeping each board's EEPROM as `settings-<userid>.hex`.

**Architecture:** Port the sibling STM32 jig (UI, state machine, WiFi/OTA/web, FFat) and replace its wire/device layers with `icsp` (bit-banged HV ICSP) and `pic18k22` (device table + memory ops). A host-testable `script` runner sits between the UI and the device through a function-pointer interface; `ihx` grows multi-region parse and write.

**Tech Stack:** Arduino (arduino-cli 1.3.1, esp32 core 3.3.0), TFT_eSPI 2.5.43 (Setup206), WiFiManager 2.0.17, FFat, host gcc for tests.

**Spec:** `docs/design.md`

## Global Constraints

- Target family: PIC18(L)F23/24/25/26/43/44/45/46K22, programming spec DS41398. HV ICSP only, VPP 9 V (7.8–9.0 V allowed).
- Regions (byte addresses): flash 0x000000, user ID 0x200000 (8 B), config 0x300000 (14 B), device ID 0x3FFFFE (2 B, part = ID & 0xFFE0), EEPROM 0xF00000.
- Waits: bulk erase 15 ms, row program 1 ms, config byte 5 ms, EEPROM byte 4 ms, user ID 5 ms. Write row = 64 bytes.
- Pins (`config.h`): PGD = GPIO1, PGC = GPIO2, MCLR_LOW = GPIO3 (high = MCLR pulled to GND), VPP_ON = GPIO10 (high = 9 V on MCLR). Never both high; ≥ 5 µs dead time between them.
- Red FAIL = verify mismatch only. Comm errors retry the whole script 3×, then orange `comm error`. Script errors: orange notice with line number, no retry.
- Auto mode runs `/flash.txt` once per insertion; never re-run on a board that stays seated.
- WiFi never blocks flashing. Hostname / AP name `PIC18Flasher`.
- FFat file names: `[A-Za-z0-9._-]`, ≤ 31 chars.
- Never `git add -A` / `git add .`; stage files by path. Commits go through the `commit-review` skill.

## Review Focus

1. **HEX from XC8 with config records split across 0x300000–0x30000D plus user ID records** — the parser must route each byte to its region, not reject the file. Test: `test_ihx_xc8_layout` (Task 1).
2. **A file whose records straddle a region boundary or sit in a gap (e.g. 0x200008)** — rejected at load with the address in the message, nothing written. Test: `test_ihx_gap_rejected` (Task 1).
3. **A script with Windows line endings or trailing spaces** (edited in a browser on Windows) — must run identically. Test: `test_script_crlf` (Task 2).
4. **Power or contact lost between `erase chip` and `write settings-{id}.hex`** — the settings file was already saved by `read` before the erase, so a rerun on the (now blank-ID) board must NOT overwrite it. The blank-userid stop covers this. Test: `test_script_blank_id_after_failed_run` (Task 2).
5. **Config verify on a part where unimplemented bits read 0** — must not FAIL. Test: `test_script_config_mask` (Task 2).

- Produces (`ihx.h`):
```c
enum { IHX_FLASH, IHX_USERID, IHX_CONFIG, IHX_EEPROM, IHX_NREGIONS };
struct ihx_region { uint32_t base, size; uint8_t *data, *mask; };  // mask[i]=1: byte present
struct ihx_image  { ihx_region r[IHX_NREGIONS]; };
// Caller fills base/size/data/mask (sizes from the detected part). Clears data to 0xFF and
// masks to 0 first. Returns false + message in err on bad checksum, unknown record type,
// or a byte outside every region ("0x200008 outside chip").

// Emits one region's masked bytes: type-04 record per 64 KB page, 16-byte type-00 records
// (split at mask gaps), then ":00000001FF". Returns bytes written (0 = out too small).
size_t ihx_write(const ihx_image *img, int region, char *out, size_t outmax);
```

### Task 2: Script parser and runner

**Files:**
- Create: `script.h`, `script.cpp`, `tests/test_script.c`
- Modify: `Makefile` (`test` also builds and runs `tests/test_script.c script.cpp ihx.cpp`)

**Interfaces:**
- Consumes: `ihx.h` (Task 1).
- Produces (`script.h`):
```c
struct pic_ops {                    // real one in pic18k22.cpp, fake in tests
  uint32_t size[IHX_NREGIONS];      // of the detected part
  const uint8_t *config_mask;       // 14 bytes, implemented bits
  bool (*read)(int region, uint32_t off, uint8_t *buf, size_t n);              // false = comm error
  bool (*write)(int region, uint32_t off, const uint8_t *buf, const uint8_t *mask, size_t n);
  bool (*erase)(bool chip);         // true = chip, false = EEPROM only
  bool (*ee_locked)();              // CONFIG5H (0x300009) bit 7 == 0
  void (*reset)();
};
struct fs_ops {
  char *(*load)(const char *name);                       // malloc'd, NUL-terminated; nullptr if missing
  bool  (*save)(const char *name, const char *text, size_t len);
};
enum script_result { SCRIPT_PASS, SCRIPT_FAIL, SCRIPT_COMM, SCRIPT_ERROR };
struct script_status { script_result result; int line; char msg[48]; };  // msg e.g. "blank userid", "verify 0x000104"
// progress(line, text) is called before each command (UI shows it).
script_status script_run(const char *script, const pic_ops *dev, const fs_ops *fs,
                         void (*progress)(int line, const char *text));
```
- Rules (from spec): `{id}` = userid bytes 0..7 as 16 uppercase hex, read once before line 1, only if `{id}` appears; all 0xFF → `SCRIPT_ERROR` "blank userid", line of first `{id}` use, no device call other than that read. `read eeprom` when `ee_locked()` → `SCRIPT_ERROR` "EE locked". Missing file → `SCRIPT_ERROR` "no <file>". Any `dev` call returning false → `SCRIPT_COMM`. Verify compares config bytes under `config_mask`; first mismatch → `SCRIPT_FAIL` "verify 0x<addr>". Unknown command / wrong arg count → `SCRIPT_ERROR` "syntax". Region words: `flash userid config eeprom`. Strip `#` comments, `\r`, surrounding whitespace.
- Image buffers: `script_run` allocates one `ihx_image` sized from `dev->size` (use `malloc`; on ESP32 that lands in PSRAM above the threshold) and frees it on return.

### Task 3: ICSP wire layer + PIC18 K22 device layer

**Files:**
- Create: `icsp.h`, `icsp.cpp`, `pic18k22.h`, `pic18k22.cpp`, `tests/test_parts.c`
- Modify: `Makefile` (`test` also builds `tests/test_parts.c pic18k22.cpp` with `-DHOST_TEST`, which compiles out the `icsp` calls)

**Interfaces:**
- Produces (`icsp.h`):
```c
void     icsp_init();                    // MCLR_LOW on, VPP off, PGC/PGD low outputs
void     icsp_enter();                   // PGC/PGD low, MCLR_LOW off, 5 µs, VPP_ON on, 100 µs
void     icsp_exit();                    // VPP off, 5 µs, MCLR_LOW on, PGC/PGD inputs
void     icsp_core(uint16_t instr);      // command 0000 + 16-bit instruction
uint8_t  icsp_tblrd_postinc();           // command 1001, 8 dummy clocks, 8 clocks data out
uint8_t  icsp_shift_tablat();            // command 0010
void     icsp_tblwr(uint8_t cmd, uint16_t data);   // 1100/1101/1111 + 16-bit payload
void     icsp_start_prog(uint16_t data, uint32_t hold_us);  // 1111, 4th PGC held high hold_us (P9), then 100 µs low (P10), then NOP
void     icsp_nop_hold(uint32_t us);     // 0000 0000 with PGD held low for us (bulk erase P11)
```
  Bit order: 4-bit command and 16-bit payload LSB first; target latches PGD on PGC falling edge; read data is valid after PGC rising edge, sample before falling edge. Direct GPIO register access (`GPIO.out_w1ts` etc.) as in the sibling `swd.cpp`; each half period = `ICSP_HALF_PERIOD` CPU cycles via `esp_cpu_get_cycle_count()`.
- Produces (`pic18k22.h`):
```c
struct pic_part { uint16_t id; const char *name; uint32_t flash; uint16_t eeprom; };
const pic_part *pic_lookup(uint16_t devid);    // devid & 0xFFE0; nullptr if unknown
const char *pic_probe();                       // enter, read 0x3FFFFE/F, exit; "no target" (0x0000/0xFFFF),
                                               // part name, or "unknown 0x5400"; latches the part
const pic_part *pic_part_detected();           // nullptr unless last probe matched the table
extern pic_ops pic_dev;                        // script backend; sizes/mask filled by pic_probe()
```
- Device table (spec): F/LF IDs 0x5740/0x5760 23K22, 0x5700/0x5720 43K22 (8 KB, 256 B); 0x5640/0x5660 24K22, 0x5600/0x5620 44K22 (16 KB, 256 B); 0x5540/0x5560 25K22, 0x5500/0x5520 45K22 (32 KB, 256 B); 0x5440/0x5460 26K22, 0x5400/0x5420 46K22 (64 KB, 1 KB). Name e.g. `PIC18LF46K22`.
- Config mask (offsets 0x00–0x0D): `00 FF 1F 3F 00 BF C5 00 xx C0 xx E0 xx 40` with `xx` = `0F` for 32/64 KB parts, `03` for 8/16 KB parts.
- Instruction words (PIC18 encodings; access-bank SFRs): `MOVLW k`=0x0E00|k; `MOVWF TBLPTRU/H/L`=0x6EF8/0x6EF7/0x6EF6; `MOVWF EEADR/EEADRH/EEDATA`=0x6EA9/0x6EAA/0x6EA8; `MOVF EEDATA,W`=0x50A8; `MOVWF TABLAT`=0x6EF5; `BSF/BCF EECON1,EEPGD`=0x8EA6/0x9EA6; `BSF/BCF EECON1,CFGS`=0x8CA6/0x9CA6; `BSF/BCF EECON1,WREN`=0x84A6/0x94A6; `BSF EECON1,WR`=0x82A6; `BSF EECON1,RD`=0x80A6; NOP=0x0000.
- Memory ops (DS41398 §3; **check each value against DS41398 Table 3-1 / §3.x before coding — the erase codes and P9/P10/P11 are the ones to confirm**):
  - Set pointer: MOVLW U, MOVWF TBLPTRU, MOVLW H, MOVWF TBLPTRH, MOVLW L, MOVWF TBLPTRL.
  - Read flash/userid/config/devid: set pointer, `icsp_tblrd_postinc()` per byte.
  - Bulk erase: pointer 0x3C0005 ← `icsp_tblwr(0b1100, 0x0F0F)`, pointer 0x3C0004 ← `icsp_tblwr(0b1100, 0x8F8F)` for chip (0x0F8F); EEPROM only = 0x0084 (`0x0000` then `0x8484`); then NOP, `icsp_nop_hold(15000)`.
  - Flash/userid write: BSF EEPGD, BCF CFGS, BSF WREN; per 64-byte row (8 for userid): set pointer, 31× (userid: 3×) `icsp_tblwr(0b1101, word)`, last word via `icsp_start_prog(word, 1000)` (userid: `5000`). Rows with an all-zero mask are skipped; partial rows are padded with 0xFF.
  - Config write: BSF EEPGD, BSF CFGS, BSF WREN; per masked byte with a nonzero config mask: set pointer to 0x30000N, `icsp_start_prog(b | b << 8, 5000)`.
  - EEPROM read: BCF EEPGD, BCF CFGS; per byte: MOVLW lo, MOVWF EEADR, MOVLW hi, MOVWF EEADRH (1 KB parts only), BSF RD, MOVF EEDATA,W, MOVWF TABLAT, NOP, `icsp_shift_tablat()`.
  - EEPROM write: BCF EEPGD, BCF CFGS, BSF WREN; per masked byte: EEADR/EEADRH, MOVLW b, MOVWF EEDATA, BSF WR, NOP, NOP, wait 4 ms; BCF WREN at the end.
  - `pic_dev.read/write/erase/ee_locked/reset` wrap these; `reset` = `icsp_exit()`. Each op enters programming mode if not already in it (flag), so a script is one continuous session.
